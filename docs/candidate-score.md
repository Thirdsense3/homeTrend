# 상승 후보 점수 v1

목적은 현재 거래 신호가 강한 지역을 비교하는 것이다. 5년 내 급등을 예측하는 모델은 아직 아니다. 사용자 화면에는 `상승 후보 (실험)`으로 표시한다.

## 계산

신고 진행 중인 마지막 달을 제외한 가격·거래량 지표를 사용한다. 각 구간 사이를 선형으로 0~배점에 대응시키고 범위를 벗어나면 양 끝 값으로 제한한다.

| 지표 | 0점 기준 | 만점 기준 | 배점 |
|---|---:|---:|---:|
| 3개월 가격 변화 | -3% | +6% | 25 |
| 12개월 가격 변화 | -10% | +15% | 25 |
| 36개월 중위 거래량 대비 | -30% | +60% | 30 |
| 최근 6개월 월 중위값 기반 전세가율 | 35% | 75% | 20 |

배점과 범위는 실험용 가정이며 학습·확률 교정으로 결정한 값이 아니다. 완성월 36개 이상, 거래가 있는 완성월 30개 이상, 최근 3개 완성월 평균 거래 10건 이상, 모든 입력 지표가 있을 때만 계산한다. 정적 빌드에서 수집 실패가 있었던 지역은 점수를 비운다. 서버 조회는 수집 실패 시 요청 자체가 실패한다.

## 탐색 평가

`node scripts/evaluate-candidates.js dist/data 60`으로 실제 데이터 빌드를 평가할 수 있다. 데모 데이터는 거부한다. 각 평가 시점의 점수는 그 시점까지의 거래만 사용하며, 결과 가격 변화는 이후 시점까지의 보정 지수에서 같은 두 달을 비교한다. 평가 기간은 개월 단위로 지정한다.

2026-10-09T23:05:46.727Z 배포 데이터를 내려받아 51개 지역의 60개월 데이터를 확인했다.

- 60개월 뒤 평가: 유효 표본 0개. 입력 36개 완성월과 이후 60개 완성월이 모두 필요하므로 최소 97개월의 월 목록이 필요하다.
- 12개월 뒤 탐색 평가: 102개 지역·시점 표본. 전체 평균 변화 +9.35%, 점수 상위 1/4 +13.30%, 하위 1/4 +4.63%.

이 결과는 장기 예측 성능의 증명이 아니다. 같은 지역의 평가 기간이 중첩되고, 상·하위 집계는 시점별 순위가 아닌 전체 표본 요약이며, 학습·검증 분리와 신뢰구간도 없다. 최근 수준으로 재조정되는 구성 보정 지수의 추정 오차도 있다. 향후 평가에는 시점별 순위, 기준 모델 비교, 표본 밖 검증, 공급·교통·정비사업 데이터, 급등의 명시적 정의가 필요하다.
