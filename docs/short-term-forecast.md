# 단기 가격 예측 v1

3·6개월 뒤 **지역의 구성 보정 평당가 3개월 이동평균 변화율**을 예측한다. 단지별 매매가·급등 확률·5년 전망은 제공하지 않는다. 단기 모델은 기존 `상승 후보` 관측 점수와 별개다.

## 데이터와 모델

- 마지막 신고 진행월을 제외한다. 예측의 시작은 마지막 완성 **기준월**이며 화면에 기준월과 목표월을 함께 표시한다. 예를 들어 2026년 8월 기준 3개월 뒤는 2026년 11월이다. 화면을 보는 오늘부터 3개월을 의미하지 않는다.
- 최소 24개월 이력, 최근 24개월 중 거래가 있는 달 20개, 최근 3개월 월평균 거래 10건, 가격·거래량·전세 지표가 필요하다. 월 목록이 끊겼거나 수집 실패가 있는 지역은 제외한다.
- 과거 기준월마다 그 달까지 거래를 먼저 자른 뒤 구성 보정 지수를 재계산한다. 전체 기간으로 추정한 지수를 앞부분만 잘라 특징으로 쓰지 않는다.
- 특징은 로그 3개월·12개월 가격 변화, 장기 기준 대비 거래량, 전세가율이다. 표준화 통계도 학습 표본에서만 계산한다.
- 미리 고정한 릿지 회귀(표준화 계수 벌점 = 학습 표본 수)와 최근 3개월 추세를 50% 감쇠해 연장하는 모델을 비교한다. 회귀의 목표는 미래의 로그 가격 변화다. 학습에는 목표월이 기준월까지 도달한 표본만 쓴다. 예측 로그 변화는 ±0.5 이내로 제한하며 검증에도 동일하게 적용한다.
- 목표 변화율은 목표월까지 추정한 구성 보정 지수에서 시작월과 목표월을 비교한다. 수준 재조정이 서로 다른 지수를 직접 나누지 않는다. 이 목표 자체도 추정치이며 나중에 정정될 수 있다.

## 시간 순서 검증과 표시 기준

1. 모델 선택용 기준월 6개에서 순차적으로 학습하고 예측한다.
2. 모델 선택 기간의 마지막 목표월이 확인될 때까지 3·6개월의 간격을 둔다. 이 결과로 회귀와 추세 감쇠 중 하나를 선택하고, 절대 로그 오차의 80% 분위수로 오차 참고 범위를 정한다.
3. 이후 최종 검증용 기준월 6개에서 선택된 모델을 고정하고, 당시까지 확인된 결과로만 매월 재학습한다. 모델 선택에 이 검증 결과를 재사용하지 않는다.
4. 최종 검증의 기준월이 6개, 표본이 200개 이상이고, 평균 절대 변화율 오차(MAE)가 가격 유지(0% 변화)보다 5% 이상 작으며, 오차 범위의 실제 포함률이 70% 이상이어야 해당 기간의 예측을 표시한다. 모델 선택 표본도 6개 기준월·200개 이상이어야 한다.
5. 해당 지역의 최종 검증 표본이 6개 이상이며 지역 MAE도 가격 유지 기준보다 작아야 표시한다. 기준 미달이면 숫자를 숨기고 보류 이유를 표시한다.
6. 최신 예측은 현재까지 목표월이 확인된 표본으로 다시 학습한다. 최신 오차 참고 범위는 모델 선택이 끝난 뒤의, 현재까지 결과가 확인된 최근 최대 12개 기준월의 순차 검증 오차로 갱신한다.

기간 분리는 [Forecasting: Principles and Practice의 rolling-origin 검증](https://otexts.com/fpp3/tscv.html)을 참고했다. 오차 범위는 과거 로그 오차를 예측에 더하고 빼서 변화율로 변환한다. 통계적으로 보장된 80% 예측구간·상승 확률이 아니다.

## 한계

- 계약일 기준 데이터이며 과거 신고일·공개 시점과 정정·취소 이력을 갖고 있지 않다. 당시 미신고 거래나 사후 수정이 포함될 수 있어 완전한 시점별 정보 백테스트가 아니다. 미래 계약월을 직접 학습에 넣지 않는 것만으로 이 문제가 해소되지 않는다.
- 60개월 중 제한된 기간만 평가했다. 인접 월의 목표 기간이 겹치고 지역도 서로 연관돼 305개를 독립 표본 305개로 해석할 수 없다. 각 지역별 평가는 6개 기준월에 불과하다.
- 오차 범위는 과거 자료를 공유한 전체 지역 기준이다. 미래 시장 변화나 특정 지역의 포함률을 보장하지 않는다. 70% 통과 기준은 제품의 실험용 노출 조건이며 확률 교정의 증명이 아니다.
- 공급·금리·교통·정비사업·향후 정책 변화는 반영하지 않았다. 짧은 검증 기간과 모델 선택 편향 때문에 외부 검증·추가 기간 검증이 필요하다.

## 재현과 배포

`node scripts/evaluate-forecasts.js dist/data [출력 JSON 경로]`로 실제 빌드의 v1/v2 지역 데이터를 읽어 재현한다. 데모 데이터는 평가를 거부한다. `npm run build`는 지역 수집 후 학습·검증해 `dist/data/forecasts.json`을 함께 생성한다. 데모 빌드는 숫자를 생성하지 않는다.

정적 사이트는 예측 JSON을 한 번 읽는다. 서버의 `/api/forecasts`는 현재 데이터 원천·기준월과 맞는 빌드 산출물을 제공한다. 지역·단지 조회 요청 중 전 지역의 API를 수집하거나 학습하지 않는다. 서버에서 예측을 보려면 먼저 같은 데이터 원천으로 빌드를 완료해야 한다. 누락·오래된 파일·조회 실패 시 기존 가격 화면은 유지하며 예측은 제공하지 않는다. 지역 화면의 거래 유형·조회 기간 필터와 별개로 전체 거래의 60개월 빌드 결과를 사용한다. 중개거래만 보기에서는 예측을 숨긴다.
