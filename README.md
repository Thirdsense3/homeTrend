# homeTrend — 서울·경기 아파트 실거래 트렌드

구별 평당가 추세, 거래량, 전세가율, 시장 국면(벌집순환모형)을 한눈에 보고
단지별 실거래 차트로 "언제 살지"를 판단하는 데 참고하는 대시보드.

## 실행

```bash
cp .env.example .env   # MOLIT_API_KEY 입력 (없으면 데모 데이터로 동작)
npm start              # http://localhost:3000
```

의존성 없음 (Node 16+). 테스트: `npm test` (Node 18+)

**사이트:** https://thirdsense3.github.io/homeTrend/ — 매일 04:00(KST) 자동 갱신

## 배포 (GitHub Pages)

`.github/workflows/deploy.yml`이 매일 새벽, 그리고 main에 push할 때마다
국토부 데이터를 받아 `npm run build`로 정적 사이트(`dist/`)를 만들어 Pages에 배포한다.
서버 없이 브라우저가 `data/region/{지역코드}.json`을 받아 직접 계산한다 (`lib/analyze.js` 공용).

- 저장소 Secrets에 `MOLIT_API_KEY` 필요: `grep '^MOLIT_API_KEY=' .env | cut -d= -f2- | gh secret set MOLIT_API_KEY`
- 받은 원본 데이터는 Actions 캐시에 보관 → 매일 최근 2개월만 다시 받음 (1년 이내 매매는 해제 반영을 위해 1주일마다)
- 첫 실행은 5년치 전체라 1~2시간. 일일 호출 한도에 걸리면 다음 날 이어서 받고, 실패가 5% 넘으면 이전 사이트 유지
- 정적 사이트의 기간 선택은 3년/5년 (10년 이상은 로컬 서버에서)

로컬에서 정적 빌드만 확인: `BUILD_MONTHS=36 npm run build` → `dist/`

## 실데이터 API 키 발급 (무료)

1. [공공데이터포털](https://www.data.go.kr) 로그인
2. 아래 두 API 각각 **활용신청** (자동승인, 보통 1시간 내 사용 가능)
   - 국토교통부_아파트 매매 실거래가 자료 (`RTMSDataSvcAptTrade`)
   - 국토교통부_아파트 전월세 실거래가 자료 (`RTMSDataSvcAptRent`)
3. 마이페이지의 **일반 인증키(Decoding)** 를 `.env`의 `MOLIT_API_KEY`에 입력

호출은 (지역 × 월) 단위로 `data/cache/`에 저장되고, 최근 2개월은 12시간마다, 1년 이내 매매는 계약 해제 반영을 위해 1주일마다 갱신.
개발계정 일일 호출 한도가 있으니 처음엔 미리 받아두면 편함:

```bash
npm run prefetch -- 36 서울   # 서울 전 구, 36개월
npm run prefetch -- 36 경기
```

## 화면

- **지역 개요 (서울/경기 탭)** — 국면 지도(가격 변화 × 거래량 변화), 구별 평당가·3/12개월 변화·고점 대비·거래량·국면·24개월 스파크라인
- **지역 상세** — 평당 매매/전세 추이, 월별 거래량, 단지 목록(최고가 대비 하락폭으로 정렬 가능), ★ 관심단지
- **단지 상세** — 평형별 매매·전세 실거래 산점도 + 6개월 이동평균, 전세가율·갭, 최근 거래, 네이버부동산 매물 링크
- **관심단지** — ★한 단지 요약 (브라우저에 저장)

## 지표

| 지표 | 계산 |
|---|---|
| 평당가 | 거래가 ÷ (전용면적 ÷ 3.3058). 월 중위값은 점으로 표시하고, 추세선은 단지 구성 보정 지수(log 평당가 = 단지·평형 효과 + 월 효과)의 3개월 이동평균. 수준은 최근 6개 완성월의 원래 이동평균에 맞춤 |
| 고점 대비 | 조회 기간 내 이동평균 최고점 대비 현재. 가격 지표는 신고 진행 중인 지난달을 빼고 계산 |
| 거래량 변화 | 최근 3개월 평균 vs 직전 3개월 (신고 진행 중인 지난달 제외) |
| 전세가율 | 최근 6개월 평당 전세 중위 ÷ 평당 매매 중위 |
| 국면 | 가격 ±1.5%, 거래량 ±15% 기준으로 벌집순환모형 6국면 분류 |

## 한계

- **호가(매물 가격)는 없음.** 공개 API가 없고 호갱노노·네이버·KB는 스크래핑을 금지함 → 단지 화면에서 네이버부동산으로 링크.
- 실거래 신고기한이 30일이라 최근 1~2개월 데이터는 계속 늘어남.
- 지역 코드는 `data/regions.json`에서 추가·수정 가능. 화성시는 2026년 일반구 설치로 41590 → 동탄구 41597 · 병점구 41595 · 효행구 41593 · 만세구 41591로 바뀜 (과거 거래도 새 코드로 조회됨).
- 국면·지표는 과거 거래 기반 참고 정보이며 투자 조언이 아님.
